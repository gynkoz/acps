Terakhir diperbarui: 30 Agustus 2026

KasirKu ("aplikasi", "kami") dikembangkan dan dikelola oleh Shandyawira. Kebijakan Privasi ini menjelaskan bagaimana kami menangani data Anda saat menggunakan aplikasi KasirKu. Dengan menggunakan aplikasi, Anda menyetujui praktik yang dijelaskan di sini.

1. Data yang Kami Kumpulkan

KasirKu dirancang untuk bekerja offline-first. Hampir semua data usaha Anda disimpan secara lokal di perangkat Anda dan tidak pernah dikirim ke server kami:

  • Data usaha — daftar produk, harga, transaksi penjualan, piutang, laporan, dan pengaturan toko (misal nama toko).
  • Akun Google — alamat email dan nama tampilan, hanya saat Anda memilih untuk masuk dengan Google.
  • Izin akses — token otorisasi untuk mengakses Google Drive Anda, hanya jika Anda mengaktifkan fitur backup.

2. Cara Kami Menggunakan Data

  • Menjalankan fitur kasir, katalog, transaksi, dan laporan di perangkat Anda.
  • Menampilkan identitas akun (email & nama) saat Anda masuk dengan Google.
  • Melakukan backup data Anda ke Google Drive (folder aplikasi tersembunyi) bila fitur backup diaktifkan — ini satu-satunya akses data Anda ke luar perangkat.

Kami tidak menjual, menyewakan, atau membagikan data Anda kepada pihak ketiga mana pun. Kami tidak menampilkan iklan berdasarkan data usaha Anda.

3. Akses Google Drive & Backup

Jika Anda mengaktifkan fitur backup, KasirKu meminta izin untuk mengunggah dan mengunduh file backup ke folder app data khusus di akun Google Drive Anda (scope drive.appdata). Kami hanya dapat membaca/menulis file yang kami buat sendiri di folder tersebut — bukan file lain di Drive Anda. Anda dapat mencabut akses ini kapan saja melalui halaman keamanan akun Google Anda.

4. Izin Aplikasi

  • Bluetooth — untuk mencetak struk thermal (printer 58/80 mm).
  • Internet — hanya untuk fitur yang memerlukannya (login Google, backup Drive, pembaruan).
  • Notifikasi — untuk pengingat lokal (misal pengingat backup).

5. Penyimpanan & Keamanan

Data Anda disimpan di penyimpanan internal perangkat Anda. Backup (jika diaktifkan) dilindungi oleh akun Google Anda. Anda dapat menghapus seluruh data aplikasi kapan saja melalui pengaturan perangkat.

6. Hak Anda

Anda berhak untuk: mengakses, mengoreksi, atau menghapus data usaha Anda; menonaktifkan backup kapan saja; mencabut izin Google melalui halaman akun Google Anda; dan menghapus aplikasi beserta datanya dari perangkat.

7. Perubahan Kebijakan

Kami dapat memperbarui kebijakan ini sewaktu-waktu. Perubahan penting akan diumumkan melalui aplikasi. Tanggal "Terakhir diperbarui" di atas menunjukkan versi terbaru.
